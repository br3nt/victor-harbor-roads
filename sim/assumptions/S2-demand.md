# Assumptions — S2-demand

Each entry: value, reason, expected sensitivity, and what evidence would replace it. Sourced values are not listed here; they carry their source id in the data files.

All numeric parameters live in ONE file, `sim/data/demand/config/default.json` (value, unit, basis, note, and sensitivity for assumptions). The tables at the end of this page are generated from it (`python -m vhsim.demand.assumptions`; a test fails if they drift). Change a value for a sensitivity run without touching code:

```
python -m vhsim.demand.build --condition summer_peak --year 2025 --growth base --set visitors.summer_vhr_target=13000
python -m vhsim.demand.build --condition all --year all --growth all --config my-variant.json
python -m vhsim.demand.validate --set gravity.beta.supermarket=2.0      # land-use sanity report
```

## Validation (land use only, before calibration)

`python -m vhsim.demand.validate` writes `sim/data/demand/VALIDATION.md` and `validation.csv`: supermarket trips vs weight, same-suburb and centre/McCracken shopping shares, mean trip length by purpose (assumed plausible ranges), in-area vehicle-km per household and per car, gateway crossings vs DIT AADT (GEH), the hourly shape vs the S3 profile, and trips into the town-centre cordon 07–19 vs the 2017 count (~7,600, S-D19).
