Victor Harbor Integrated Transport Strategy

How would the road options change Victor Harbor?

An independent traffic simulation of Victor Harbor, built by a resident. It compares today's roads with the City of Victor Harbor's proposed town-centre changes and with alternatives, on a school-term weekday and a summer holiday day, now and as the town grows. Results are preliminary: read them as differences between options on the same traffic, not as exact forecasts.

Source code and data

Everything behind this site (the simulation, the viewers, the game, the notes and the source lists) is in the repository github.com/br3nt/victor-harbor-roads. Council documents and other archived sources are not copied: the knowledge base's Sources Register lists each one with its address and checksum.

A post in a public community Facebook group is cited only as a sign of public sentiment; members of the public are not named. Everyone else named is acting in a public or professional role, or is the author.
