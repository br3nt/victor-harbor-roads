Scenario definitions

Each scenario = a network patch over the baseline (S1) and/or a demand variant (S2), run under each condition (weekday_term, saturday, summer_peak, event_nye) and demand year (2025/base, 2031|2041|2051 × moderate|high). Ids match the knowledge base Options Register (site/options-register.html).

Where the council has not defined an option precisely, the definition below is our reading of its map, marked Inference, and a variant tests the main alternative reading. Sources: VHITS town-centre map (S-A04c, S-B03 p.93), Vision map (S-B03 p.92), ring-road map (S-A04b, S-B03 pp.91, 94), fact sheet (S-A03), survey text (S-A05).
